TRMNL Debug

Finds a TRMNL (X: ESP32-S3, OG: ESP32-C3) over USB and restarts it with an RTC watchdog reset, the same reset as esptool --after watchdog-reset. Useful for the X, which has no reset button.

This browser has no Web Serial. Use Chrome or Edge on a desktop computer.

No device chosen.

  • Detect: enters the ROM bootloader, reads chip and MAC, then watchdog-resets back to the app.
  • Watchdog reset: enters the ROM bootloader and watchdog-resets the chip.
  • Read boot log: reads the serial port for 8 s (if the port came back late).
  • Not found? Put the device in flashing mode by hand: TRMNL's guide.

Safe by design: this page never writes or erases flash and never touches eFuses. It only reads chip registers and writes the RTC watchdog, super watchdog and force-download-boot registers.
